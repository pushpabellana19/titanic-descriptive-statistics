# Titanic Descriptive Statistics

## Task Overview
This project was completed as part of the Veda Technology internship, Task 9: Descriptive Statistics Primer.

## Objective
To calculate and interpret descriptive statistics using the Titanic dataset.

## Dataset
The Titanic passenger dataset contains information such as passenger ID, survival status, passenger class, age, and ticket fare.

## Tools Used
- Google Sheets
- GitHub

## Analysis Performed
The project includes a summary statistics table with:
- Mean
- Median
- Mode
- Standard deviation
- 25th percentile
- 50th percentile
- 75th percentile

## Key Findings
- The average passenger age was approximately 29.36 years, and the median age was 28 years.
- The average ticket fare was approximately 32.20, higher than the median fare of approximately 14.45.
- The survival rate was approximately 38.4%.
- The fare distribution appears right-skewed, suggesting some passengers paid considerably higher fares.
- The standard deviation of age was approximately 13.02 years.

## Conclusion
This project demonstrates how descriptive statistics can summarize a dataset and reveal patterns in passenger age, ticket fares, and survival.
